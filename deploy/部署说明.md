# 真好玩服务器部署

1. 上传本包到服务器，例如 `/opt/zhw-mini`。
2. 确认证书已存在：
   - `/etc/nginx/ssl/haowan.net.cn/fullchain.pem`
   - `/etc/nginx/ssl/haowan.net.cn/privkey.pem`
3. 修改 `deploy/env.prod` 中未填写的第三方配置。
4. 启动：
   ```bash
   cd /opt/zhw-mini/deploy
   docker compose -f docker-compose.prod.yml --env-file env.prod up -d --build
   ```
5. 查看状态：
   ```bash
   docker compose -f docker-compose.prod.yml ps
   docker compose -f docker-compose.prod.yml logs -f go-api
   ```
6. 将 `cdn-assets/miniprogram` 目录内容上传到 COS 的 `miniprogram/` 前缀，对应访问域名为 `https://static.haowan.net.cn/miniprogram/...`。
