# 真好玩第三方接口与上线资质清单

更新时间：2026-06-23

本文只保留三类信息：接什么接口、费用、上线是否需要证照或资质。价格以官方页面、控制台、商户合同和实际开通页为准。

## 1. 第三方接口与费用

| 模块 | 阶段 | 接什么接口 / 能力 | 用途 | 费用结论 |
| --- | --- | --- | --- | --- |
| 微信小程序登录 | 一期必接 | `wx.login`、服务端 `code2Session` | 获取 OpenID / UnionID，完成邀请注册后的微信登录 | 接口未见单独按次收费；需要小程序 AppID、主体认证和备案 |
| 邀请入口 | 一期必接 | 小程序分享卡片、`getUnlimitedQRCode`、`generateUrlLink`、`scene` 参数 | 海报/卡片、二维码、链接三种邀请入口；每次生成唯一邀请码 | 微信接口未见单独按次收费；受接口规则、有效期、路径和参数长度限制 |
| 手机号绑定 | 一期建议 | 微信手机号能力 `getPhoneNumber` | 用户绑定手机号、实名前置、运营联系 | 微信接口未见单独按次收费 |
| 短信验证码 | 一期可选兜底 | 腾讯云短信 SMS | 手机验证码、异常登录、后台通知兜底 | 收费；官方套餐示例：1万条 470 元/2年，10万条 4500 元/2年，100万条 43000 元/2年 |
| 实名认证 | 一期必有流程，自动核验可分阶段 | 腾讯云慧眼人脸核身 / 实名信息核验 | 行家、领路人实名认证；玩家不强制实名 | 收费；按计费调用次数收费，支持预付费/后付费，具体以控制台资源包或商务开通为准 |
| 身份证 OCR | 一期可选 | 腾讯云 OCR 身份证识别 | 自动识别姓名、身份证号、有效期，减少人工录入 | 收费；OCR 产品页显示 0.011 元/次起，实际按所选接口和套餐计费 |
| 地图定位 / 附近的局 | 一期必接 | 微信定位 `wx.getLocation`、小程序原生 `<map>`、后端代理腾讯位置服务 WebService API：逆地址解析、地址解析、地点搜索、路线规划 | 创建局地点、经纬度、城市、附近距离、后台地点校验；前端只展示 marker 和请求后端 | 商业项目需要腾讯位置服务商业授权；官方商业授权基础版 50,000 元/年，高级版 70,000 元/年；已授权客户可增购流量包 300 元/十万次、QPS 400 元/10QPS/月 |
| 对象存储 | 一期必接 | 腾讯云 COS 或等价对象存储、临时上传凭证、私有下载 URL | 头像、实名材料、IM 图片/文件、后台审核附件 | 收费；按存储容量、请求次数、外网流量等计费，标准存储公开价常见为 0.099 元/GB/月起，实际以地域和计费页为准 |
| 订阅消息 | 一期建议 | 微信小程序订阅消息 `subscribeMessage.send` | 审核结果、入局结果、局状态、评价提醒 | 微信接口未见单独按次收费；需要用户授权和模板配置 |
| 内容安全 | 一期必做基础能力 | 微信内容安全接口 `msgSecCheck` / `mediaCheckAsync`，自建敏感词库；高级可接腾讯云内容安全 | 文本、图片、昵称、评论、IM 内容风险拦截 | 微信内容安全接口未见单独按次收费；腾讯云内容安全为收费增强项 |
| 微信支付 | 二期正式接入，一期只预留 | 微信支付 JSAPI 下单、支付回调、退款、账单 | 收费局、会员、押金、退款、对账 | 接口本身不按开发接口收费；微信支付按商户类目和合同费率收取交易手续费 |
| 微信支付分账 | 二期正式接入 | 微信支付分账、分账回退、完结、账单 | 玩家付款后按规则给行家、领路人、平台分账 | 依赖微信支付商户号、分账能力开通、商户合同和类目费率 |
| IM | 一期必接 | 当前项目按自研 WebSocket / OpenIM 自部署方案 | 局内群聊、文件、已读、争议留痕、AI 分析数据沉淀 | OpenIM 自部署无腾讯接口费；服务器、数据库、对象存储和带宽另计 |
| AI 推荐 / AI 分析 | 二期 | 腾讯混元、向量检索、腾讯云 AI 或其他模型服务 | 推荐局、用户画像、IM 复盘、关系网分析 | 二期选型后按 token、调用量、实例资源或云服务套餐计费 |

## 2. 腾讯地图费用结论

腾讯位置服务官方页已经确认：

| 项目 | 官方费用 |
| --- | --- |
| 商业授权基础版 | 50,000 元/年 |
| 商业授权高级版 | 70,000 元/年 |
| 已授权客户流量包 | 300 元/十万次 |
| 已授权客户 QPS 增购 | 400 元/10QPS/月 |

对本项目的判断：

| 场景 | 是否需要买 |
| --- | --- |
| 仅开发测试、未商业上线 | 可先用测试额度，但要看账号身份和接口额度 |
| 小程序正式上线、企业主体、商业项目持续使用地图/定位/地点服务 | 需要商业授权，预算至少按 50,000 元/年准备 |
| 上线后调用量超过授权额度 | 再按流量包或 QPS 增购 |

## 2.1 当前后端实现口径：不用前端绑定 AppID

| 项目 | 处理方式 |
| --- | --- |
| 前端是否使用腾讯位置服务小程序 SDK | 不使用 |
| 前端是否绑定腾讯地图 Key 的小程序 AppID | 不需要 |
| 前端显示地图 | 使用微信小程序原生 `<map>` 组件展示底图和附近局 marker |
| 前端获取定位 | 使用 `wx.getLocation` 获取经纬度和精度 |
| 地点搜索 / 地址解析 / 逆地址解析 / 路线规划 | 小程序和后台前端都请求自己的后端接口，由后端使用 `TENCENT_MAP_KEY_SERVER` 调腾讯 WebService |
| Key 放在哪里 | 只放后端环境变量，不写进小程序代码 |
| 后端安全配置 | 建议配置腾讯地图服务端 Key、SK 签名、服务器出口 IP 白名单、接口限流和缓存 |
| 新增接口 | `GET /api/app/map/search`、`GET /api/app/map/geocode`、`GET /api/app/map/reverse-geocode`、`GET /api/app/map/route`、`GET /api/admin/map/search` |

前端需要做的事情只有：调用 `wx.getLocation`、调用后端地图接口、用 `<map>` 渲染后端返回的经纬度 marker。前端不要引入 `qqmap-wx-jssdk.js`，不要直连 `https://apis.map.qq.com`，不要在小程序包里写腾讯地图 Key。

## 3. 上线证照 / 资质判断

| 事项 | 一期是否需要 | 判断 |
| --- | --- | --- |
| 营业执照 / 企业主体 | 需要 | 小程序认证、微信支付、腾讯地图商业授权、实名服务开通基本都需要企业主体资料 |
| 微信小程序认证 | 需要 | 正式发布、主体可信、接口能力、后续支付能力都依赖认证主体 |
| 小程序备案 | 需要 | 微信小程序上线发布前需要按平台要求完成备案 |
| ICP 备案 | 需要 | 后端 API、管理后台、文件访问域名如果使用中国大陆服务器，必须先做 ICP 备案 |
| 公安联网备案 | 通常需要 | 域名网站/后台上线后通常需要在公安备案平台完成联网备案 |
| EDI 许可证 | 一期暂不作为上线硬前置；二期交易闭环前必须重点评估 | 一期不接真实支付、普通用户只能开免费局，暂时不按交易平台闭环运营。二期如果上线玩家向行家付款、平台撮合第三方服务、平台收款并分账/结算，属于高概率触发 EDI 评估的模式，建议在二期支付分账前咨询当地通信管理局或专业资质机构 |
| ICP 经营许可证 | 视业务模式 | 如果只是自有小程序服务和免费内测，通常先做 ICP 备案；如果向用户有偿提供互联网信息服务、会员信息服务或其他经营性互联网信息服务，需要评估 ICP 经营许可证 |
| 微信支付商户号 | 一期不需要，二期需要 | 一期不接真实支付；二期收费局、会员、押金、退款、分账上线前必须开通 |
| 等保备案 / 测评 | 建议提前规划 | 项目涉及实名、位置、IM、后台管理、资金预留。不是每个小程序上线前都立即要测评证书，但生产运营前建议至少按二级/三级做合规评估 |
| 个人信息保护合规材料 | 需要 | 需要用户协议、隐私政策、个人信息处理规则、位置授权说明、实名材料处理说明、注销入口 |
| 短信签名和模板 | 使用短信时需要 | 接腾讯云短信前需要完成签名和短信模板审核 |
| 腾讯云慧眼 / OCR 资质 | 使用自动实名时需要 | 自动实名、人脸核身、OCR 都需要按腾讯云要求开通服务、完成企业资料和接口配置 |

## 4. 当前一期上线前最小准备清单

| 优先级 | 要准备什么 | 说明 |
| --- | --- | --- |
| P0 | 小程序主体认证和备案 | 没有这个不能按正式小程序上线走 |
| P0 | 后端/API/后台域名 ICP 备案 | 只要中国大陆服务器和域名对外服务，就要备案 |
| P0 | 腾讯位置服务商业授权预算 | 商业上线按基础版 50,000 元/年准备 |
| P0 | 腾讯地图服务端 Key | 后端配置 `TENCENT_MAP_KEY_SERVER`，用于地点搜索、地址解析、逆地址解析、路线规划；不需要绑定小程序 AppID |
| P0 | 隐私政策、用户协议、邀请制说明、实名授权说明 | 审核、实名、位置、IM、举报申诉都需要有明确告知 |
| P0 | COS 或等价对象存储账号与私有桶 | 存实名材料和 IM 文件，不能公开读写 |
| P0 | 微信订阅消息模板 | 审核结果、入局结果、局状态、评价提醒 |
| P1 | 腾讯云短信签名和模板 | 如果一期只用微信手机号能力，可作为兜底 |
| P1 | 腾讯云慧眼 / OCR 开通 | 如果一期要自动实名，就提前开；如果先人工审核，可后置 |
| P1 | 公安联网备案 | 域名上线后尽快办理 |
| P2 | 微信支付商户号、分账能力、EDI/ICP 经营许可评估 | 二期真实支付和平台分账前处理 |
