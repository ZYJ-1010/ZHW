## 1. 清单说明

本清单用于开发排期、前后端分工、测试验收和客户确认。所有功能按一期必须完成、一期必须预留、后台必须支持三个维度整理。

字段说明：

| 字段 | 说明 |
| --- | --- |
| 优先级 | `P0` 为一期必须交付；`P1` 为一期建议交付或基础预留；`P2` 为二期正式建设但一期需留数据 |
| 小程序 | 用户端是否需要页面或交互 |
| 后台 | PC 管理后台是否需要页面或配置 |
| 后端 | 是否需要接口、状态机、任务、权限或业务逻辑 |
| 数据 | 是否需要数据库表、字段、索引或日志 |
| 验收口径 | 判断该功能是否完成的最小标准 |

## 15. 不通过验收的功能缺口

出现以下任一情况，功能清单视为未完成：

1. 页面存在但接口未接通。
2. 接口存在但数据库没有记录。
3. 前端隐藏按钮但后端没有权限校验。
4. 无有效邀请码也能进入小程序或注册。
5. 未实名的行家或领路人也能使用对应角色、收益或分润能力。
6. 行家、领路人未经审核即可使用。
7. 领路人未满足双门槛也能开通。
8. 人数不受 5-8 控制。
9. 每日三局限制不生效。
10. 开始后仍可入局。
11. 非成员能进入 IM 或下载文件。
12. IM 文件没有和局、房间、发送人绑定。
13. 敏感词无法拦截。
14. 局未完成即可评价或分润。
15. 确认后退出没有扣信用。
16. 分润比例写死，后台不能配置。
17. 后台无法查看全链路记录。
18. 管理员关键操作没有日志。
19. 普通管理员能查看完整操作日志。
20. 报表无法导出。
21. 行为数据未记录，无法支撑二期 AI 推荐。
