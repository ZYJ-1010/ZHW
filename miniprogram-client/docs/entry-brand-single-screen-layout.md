# 带顶部 Brand 的启动单屏页适配规则

## 适用范围

本规则仅适用于当前启动页 `pages/entry/index`，以及后续经过确认、具有相同结构的页面：顶部蓝色区域包含 Brand 和在线人数，主体包含主圆、GO 按钮、标题、拼音和底部状态圆点。

其他页面即使也是单屏，也不得直接复用本规则。它们只能复用 `utils/viewport-layout.js` 提供的设备基础数据，并建立自己的页面规则。

## 固定设计基准

- 横向设计坐标为 `750rpx`；运行时按 `750 / windowWidth` 换算，不是固定物理像素。
- 基准设备为 `375 × 667`，顶部最小高度 `182rpx`，基准内容高度 `1152rpx`。
- Brand、在线人数、圆点和顶部字号保持固定视觉规格，不随屏幕高度放大。
- 主圆基准 `400rpx`，标题基准 `400 × 260rpx`，拼音基准字号 `20rpx`。
- 内容缩放范围为 `0.78–1`：短屏最多缩至 78%，长屏只增加留白。

## 本页面动态规则

1. 顶部高度以系统状态栏和微信胶囊真实位置为准，并取动态导航底部加 `24rpx` 与 `182rpx` 中的较大值。
2. 内容高度等于视口高度减顶部高度，可用内容高度还需扣除底部安全区。
3. 缩放比例为 `clamp(usableContentHeight / 1152, 0.78, 1)`。
4. 主视觉顶部取可用高度的 13%，并限制在缩放后的 `96–184rpx`。
5. 底部圆点优先位于可用高度的 82%，同时与上方内容至少间隔缩放后的 `80rpx`，并为底部安全区预留 `80rpx`。
6. GO 按钮、票券卡片和内部图形使用相对于主圆的百分比尺寸与位置。
7. 页面在 `onLoad`、`onShow` 和 `onResize` 时重新计算。

## 代码归属

- `utils/viewport-layout.js`：只读取视口、状态栏、胶囊和安全区，不包含本页面排版规则。
- `pages/entry/layout.js`：仅包含带顶部 Brand 的启动页设计基准和纵向排版公式。
- `pages/entry/index.js`：消费布局结果并生成页面内联样式，不再复制计算公式。

## 禁止事项

- 禁止其他页面直接调用 `getEntryBrandSingleScreenLayout`，除非产品确认其结构与启动页完全相同。
- 禁止把 Brand、主圆、标题或圆点规则移回公共视口工具。
- 禁止用固定像素模拟状态栏、胶囊或安全区。
- 禁止通过页面滚动掩盖单屏内容溢出。

## 验收尺寸

- `320 × 568`
- `375 × 667`
- `375 × 812`
- `430 × 932`

每个尺寸均需确认：页面无横纵滚动、胶囊与 Brand 不重叠、主视觉完整、圆点避开安全区、Brand 与在线人数对齐不变。
