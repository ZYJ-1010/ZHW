# 小程序页面适配规则索引

## 分层原则

页面适配分为“设备基础数据”和“页面布局规则”两层，禁止把某一个页面的排版公式当成全项目通用规则。

### 设备基础数据

`utils/viewport-layout.js` 只负责提供以下中立数据：

- `750 / windowWidth` 横向换算比例
- 当前视口高度
- 系统状态栏高度
- 微信胶囊高度、底部位置和导航区域高度
- 底部安全区

公共工具不得包含 Brand、主视觉、标题、底部圆点、工具栏或业务组件的位置规则。

### 页面布局规则

每一类页面维护独立规则文件。页面只复用设备基础数据，不直接复用其他页面的排版公式。

当前规则类型：

- [带顶部 Brand 的启动单屏页](./entry-brand-single-screen-layout.md)：仅供 `pages/entry/index` 及后续明确采用同一视觉结构的页面参考。
- [带 Brand 顶栏与固定底部控制台的业务母版](./home-shell-fixed-frame-layout.md)：仅供 `components/home-shell` 及其业务页面使用。

后续新增无 Brand 页面、带底部操作栏页面、列表页面或沉浸式页面时，必须新增独立规则，不得修改或套用启动页规则。

## 命名要求

- 公共设备工具使用 `viewport-*` 命名。
- 页面规则使用“页面或结构名称 + layout”命名，例如 `pages/entry/layout.js`。
- 文档标题必须明确适用页面结构，避免使用“所有页面”“通用页面布局”等容易误用的名称。
