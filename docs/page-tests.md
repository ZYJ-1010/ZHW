# 页面测试说明

本文记录工程侧页面测试点，不修改 `00.文档` 下的正式需求文档。

## 入口页与登录前首页

本节以 2026-06-13 最新入口链路为准：小程序打开先进入 `pages/entry/index`，再到登录前首页 `pages/home/guest/index`，点击 `注册/登录` 后进入 `pages/login/index`。

### 页面

- `pages/entry/index`
- `pages/home/guest/index`
- `pages/login/index`

### 启动链路测试

1. 在微信开发者工具中打开项目。
2. 不单独指定启动页面，直接点击编译。
3. 等待进入页自动跳转，或点击 `GO`。
4. 在登录前首页点击 `注册/登录`。

预期：

- 先看到黑底 `真好玩 / ZHEN HAO WAN / GO` 进入页。
- 进入页能跳到登录前首页，不白屏。
- 登录前首页能看到 `HELLO, 玩家!`、启动旅程卡片、发起组局、局前大厅、附近正在发生。
- 顶部在线人数来自 mock/后端首页数据，不在页面里写死。
- 点击 `注册/登录` 后进入 `pages/login/index`。

### 登录页布局回归

1. 打开 `pages/login/index`。
2. 确认默认只看到 `手机号登录`、`账号密码登录` 和协议勾选。
3. 点击 `手机号登录` 后进入接收验证码登录页，显示脱敏手机号。
4. 返回登录主页后点击 `账号密码登录`，进入账号密码表单。
5. 在表单页点击 `微信登录`。
6. 在微信授权页不勾选协议点击 `允许`。
7. 勾选协议后再次点击 `允许`。

预期：

- 登录主页不直接展示手机号输入框和验证码输入框。
- 登录主页提供 `手机号登录` 和 `账号密码登录` 两种入口。
- 手机号登录页展示 6 位验证码输入框、倒计时和返回登录方式入口。
- 账号密码页只提供账号、密码和找回密码入口。
- `找回密码` 是密码登录区域的弱入口，不再和 `微信登录` 并列成主按钮。
- 微信授权页不再使用旧卡片样式，展示微信图标、授权说明、`允许` 和 `拒绝`，页面无需拖动。
- 点击 `允许` 后进入墨刀的 `进入启动页面` 过场；接口成功后进入 `pages/home/index`，接口失败则停留在微信授权页并提示错误。

## 登录与找回密码

本节以 2026-06-13 最新口径为准：默认第一个用户不需要邀请码，普通登录页只测试手机号登录、微信授权登录和找回密码。邀请码注册拆到独立邀请页。

### 页面

- `pages/login/index`
- `pages/login/invite/index`
- `pages/login/forgot/index`

### 测试数据

| 场景 | 数据 |
| --- | --- |
| 手机号 | `13888888888` |
| 账号 | `13888888888` |
| 验证码 | `123456` |
| 新密码 | `Test123456` |
| 邀请码 | `ENJOY2026` |

### 手机号登录

1. 启动页面设为 `pages/login/index`。
2. 勾选用户协议和隐私协议。
3. 点击 `手机号登录`。
4. 预期进入验证码登录页，显示手机号 `138****8888`，并提示验证码已发送。
5. 点击验证码输入框，输入验证码 `123456`。
6. 点击 `登录`。

预期：提示 `登录成功`，随后跳转 `pages/home/index`。

### 账号密码登录

1. 启动页面设为 `pages/login/index`。
2. 勾选用户协议和隐私协议。
3. 点击 `账号密码登录`。
4. 输入账号 `13888888888`。
5. 输入密码 `Test123456`。
6. 点击 `登录/注册`。

预期：提示 `登录成功`，随后跳转 `pages/home/index`。

### 微信授权登录

1. 启动页面设为 `pages/login/index`。
2. 点击 `微信登录`。
3. 在微信授权界面确认能看到微信图标、授权说明、`允许` 和 `拒绝`，页面无需拖动。
4. 点击 `允许`。

预期：接口成功后进入墨刀的 `进入启动页面` 过场，再跳转 `pages/home/index`；接口失败则停留在微信授权页并提示错误。

点击 `拒绝` 的预期：返回普通登录页，提示已拒绝授权。

### 找回密码

1. 启动页面设为 `pages/login/index`。
2. 点击 `找回密码`。
3. 输入手机号 `13888888888`。
4. 点击 `获取验证码`。
5. 输入验证码 `123456`。
6. 点击 `下一步`。
7. 输入新密码 `Test123456`。
8. 再次输入新密码 `Test123456`。
9. 点击 `确认修改`。

预期：进入 `密码重置成功` 页面；点击 `去登录` 后返回 `pages/login/index`。

### 邀请注册

1. 启动页面设为 `pages/login/invite/index`。
2. 输入邀请码 `ENJOY2026`。
3. 点击 `确认邀请码`。
4. 点击 `继续登录注册`。
5. 进入 `pages/login/index` 后，页面应显示 `已识别邀请`。
6. 勾选协议，点击 `手机号登录`，输入验证码 `123456` 并点击 `登录`。

预期：提示 `登录成功`，随后跳转 `pages/home/index`。点击 `普通登录` 应清空邀请上下文并回普通登录页。

### 异常测试

| 操作 | 预期 |
| --- | --- |
| 不勾选协议点击 `登录/注册` | 提示先同意用户协议和隐私协议 |
| 验证码页未输入满 6 位点击 `登录` | 提示请输入 6 位验证码 |
| 空手机号点击 `获取验证码` | 提示先输入手机号 |
| 错误验证码登录 | 提示手机号或验证码错误 |
| 找回密码页验证码输入 `123457` 后点下一步 | 提示手机号或验证码错误，不进入设置新密码页 |
| 找回密码页密码包含符号或不含字母/数字 | 提示仅支持字母和数字，长度8-20位 |
| 找回密码页两次新密码不一致 | 提示两次输入的新密码不一致 |
| 邀请页输入错误邀请码 | 提示邀请码无效，不能继续登录注册 |

## 通用检查

1. 页面不应出现白屏。
2. 控制台不应出现 JS 语法错误。
3. mock 模式下不依赖真实服务器。
4. 页面使用简洁白底、深色文字、微信绿强调色；等墨刀标注恢复后再做视觉细化。

## 测试点

1. 从登录页授权成功后进入首页，或直接打开 `pages/home/index`。
