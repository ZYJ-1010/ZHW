# 页面测试说明

本文记录工程侧页面测试点，不修改 `00.文档` 下的正式需求文档。

## 首页 `pages/home/index`

### 登录跳转测试

1. 启动页面设为 `pages/login/index`。
2. 勾选“我已了解并同意使用微信授权登录”。
3. 点击“同意并微信登录”。

预期：出现 `授权成功` 提示后，自动跳转到 `pages/home/index`。

### 测试步骤

1. 在微信开发者工具中打开编译模式。
2. 添加或切换启动页面为 `pages/home/index`。
3. 点击编译。

### 预期结果

1. 页面顶部显示用户昵称 `微信用户`。
2. 可看到 `待实名` 状态、今日信用、等级和会员信息。
3. 可看到实名提醒：`完成实名后可发起和参与核心组局`。
4. 可看到 6 个快捷入口：发起组局、局前大厅、申请身份、附近组局、消息、我的。
5. 可看到推荐组局列表，包含 `周末咖啡创业交流局` 和 `城市夜景拍照路线`。

### 点击测试

| 操作 | 预期 |
| --- | --- |
| 点击 `发起组局` | 跳转到 `pages/game/create/index`，不白屏 |
| 点击 `局前大厅` | 跳转到 `pages/game/hall/index`，不白屏 |
| 点击 `申请身份` | 跳转到 `pages/role/apply/index`，不白屏 |
| 点击 `附近组局` | 跳转到 `pages/map/index`，不白屏 |
| 点击 `消息` | 跳转到 `pages/message/index`，不白屏 |
| 点击 `我的` | 跳转到 `pages/profile/index`，不白屏 |

## 角色申请 `pages/role/apply/index`

### 测试步骤

1. 在微信开发者工具中打开编译模式。
2. 添加或切换启动页面为 `pages/role/apply/index`。
3. 点击编译。

### 预期结果

1. 页面标题显示 `选择你的身份`。
2. 可看到 `申请成为行家` 卡片。
3. 可看到 `申请成为领路人` 卡片。
4. 领路人卡片展示双门槛：
   - 条件达成：条件未达成
   - 付费状态：待付费确认

### 点击测试

| 操作 | 预期 |
| --- | --- |
| 点击行家卡片的 `提交申请` | 出现 `已进入审核` 提示，按钮变为 `已进入审核` |
| 点击领路人卡片的 `提交申请` | 出现 `已进入审核` 提示，按钮变为 `已进入审核` |
| 连续重复点击已提交按钮 | 按钮保持禁用，不重复提交 |

## 通用检查

1. 页面不应出现白屏。
2. 控制台不应出现 JS 语法错误。
3. mock 模式下不依赖真实服务器。
4. 页面使用简洁白底、深色文字、微信绿强调色；等墨刀标注恢复后再做视觉细化。
