# Enjoy UI Style Guide

本文记录当前小程序的基础控件规范。第一阶段只覆盖登录链路，首页和强业务模块后续单独统一。

## 适用范围

- 当前适用：登录、邀请注册、找回密码、微信授权、实名认证弹窗、新手任务弹窗中的基础控件。
- 暂不适用：首页、地图、排行榜、成就、组局卡片等强业务视觉模块。
- 组件库暂不引入，先使用项目自有 `enjoy-` 前缀样式。

## 登录链路版式

- 目标画布宽度按 `750rpx` 理解。
- 登录链路主体内容优先使用左右 `62rpx` 安全边距，对应内容宽 `626rpx`。
- 页面标题位置、表单纵向位置、弹窗位置尊重现有原型还原，本阶段不强行统一。
- 控件内部高度、圆角、字号、颜色走全局基础样式。

## 基础控件

- 样式文件：`styles/enjoy-ui.wxss`，由 `app.wxss` 全局引入。
- 输入框：
  - `.enjoy-field`：默认高度 `80rpx`，圆角 `20rpx`，背景 `#f4f4f6`。
  - `.enjoy-field--comfortable`：高度 `88rpx`。
  - `.enjoy-field--large`：高度 `104rpx`，圆角 `28rpx`。
  - `.enjoy-input`、`.enjoy-input--comfortable`、`.enjoy-input--large` 对应输入文字尺寸。
- 按钮：
  - `.enjoy-button`：默认高度 `82rpx`，圆角 `20rpx`。
  - `.enjoy-button--primary`：紫粉渐变 `#8a5cf6 -> #e44f9b`。
  - `.enjoy-button--secondary`：浅灰底、次级文字。
  - `.enjoy-button--success`：成功色 `#22c79a`。
  - `.enjoy-button--disabled` 或 disabled 态：弱灰底、弱文字。
- 验证码：
  - `.enjoy-code-box`：`78rpx x 88rpx`，圆角 `16rpx`。
  - `.enjoy-code-box--filled`：边框使用主紫色。
  - `.enjoy-code-action`：验证码文字入口统一为 `24rpx`、`#8a5cf6`、`700`。
  - `.enjoy-code-action--disabled`：倒计时或不可点状态使用 `#a8a8b2`。
- 勾选：
  - `.enjoy-check`：圆形基础勾选控件。
  - `.enjoy-check--active`：完成/选中态，使用成功色 `#22c79a`。

## 文字层级

文字层级先作为全项目统一口径，后续按模块逐步应用。默认正文不加粗，只有标题、按钮、状态、金额、倒计时等需要强调的内容提高字重。除按钮、输入框这类固定高度控件外，文字必须同时定义 `font-size` 和 `line-height`。

### 基础层级

| 层级 | 类名 | 字号 / 行高 / 字重 | 使用场景 |
| --- | --- | --- | --- |
| 页面标题 | `.enjoy-text-page-title` | `34rpx / 46rpx / 700` | 页面主标题、顶部中心标题下方的页面级标题。 |
| 导航文字 | `.enjoy-text-nav` | `28rpx / 40rpx / 600` | 顶部导航、底部导航、主要入口文字。 |
| 一级区块标题 | `.enjoy-text-section-title` | `30rpx / 42rpx / 700` | 页面内大区块标题，例如消息分类标题、列表分组标题。 |
| 二级标题 | `.enjoy-text-subtitle` | `28rpx / 40rpx / 600` | 卡片内小分组标题、弹窗小标题。 |
| 卡片标题 | `.enjoy-text-card-title` | `28rpx / 40rpx / 600` | 列表卡片主标题、消息卡片标题。 |
| 正文 | `.enjoy-text-body` | `24rpx / 36rpx / 400` | 描述、说明、列表摘要、普通内容。 |
| 强调正文 | `.enjoy-text-body-strong` | `24rpx / 36rpx / 600` | 正文里的重点词、用户名称、短状态。 |
| 辅助说明 | `.enjoy-text-caption` | `22rpx / 32rpx / 400` | 表单说明、次级文案、卡片辅助描述。 |
| 元信息 | `.enjoy-text-meta` | `20rpx / 28rpx / 400` | 时间、备注、订单号、阅读量、小计数。 |

### 控件文字

| 层级 | 类名 | 字号 / 行高 / 字重 | 使用场景 |
| --- | --- | --- | --- |
| Tab 默认 | `.enjoy-text-tab` | `30rpx / 42rpx / 500` | 顶部 tab、分类切换项默认态。 |
| Tab 选中 | `.enjoy-text-tab--active` | `30rpx / 42rpx / 700` | tab 选中态，只改颜色和字重，不改变字号。 |
| 按钮文字 | `.enjoy-text-button` | `28rpx / 36rpx / 600` | 普通按钮、底部主操作按钮。 |
| 小按钮文字 | `.enjoy-text-button-small` | `22rpx / 30rpx / 600` | 卡片内操作按钮、标签式按钮。 |
| 标签文字 | `.enjoy-text-tag` | `20rpx / 28rpx / 500` | 状态标签、角标、审核状态。 |
| 输入文字 | `.enjoy-text-input` | `26rpx / 36rpx / 400` | 输入框、textarea、搜索框内容。 |

### 特殊层级

| 层级 | 类名 | 字号 / 行高 / 字重 | 使用场景 |
| --- | --- | --- | --- |
| 大数字 | `.enjoy-text-stat` | `40rpx / 52rpx / 700` | 统计数字、积分、排行榜数值。 |
| 展示数字 | `.enjoy-text-display` | `48rpx / 60rpx / 700` | 首页大数字、重要金额、核心指标。 |
| 倒计时数字 | `.enjoy-text-countdown` | `56rpx / 66rpx / 700` | 倒计时、限时预警，不用于普通列表。 |
| 文章标题 | `.enjoy-text-article-title` | `34rpx / 48rpx / 700` | 系统通知、公告、长文内容标题。 |
| 文章正文 | `.enjoy-text-article-body` | `26rpx / 42rpx / 400` | 长文章正文，行高比普通正文更松。 |
| 聊天文字 | `.enjoy-text-message` | `26rpx / 38rpx / 400` | 聊天气泡、IM 内容。 |

### 使用规则

- 默认不要使用 `800`、`900` 字重；只在品牌字、核心金额、倒计时或强状态中按需使用。
- 同一个角色的文字不要因为页面不同随意换字号，例如卡片标题统一从 `.enjoy-text-card-title` 起步。
- 选中态、危险态、成功态优先改颜色和局部字重，不改变字号，避免切换时布局跳动。
- 按钮和输入框可以使用控件高度作为行高；其他普通文字不要用容器高度当 `line-height`。
- 新页面优先使用上述类；旧页面分模块迁移，不一次性全局硬改。

## 后续视觉系统模块

文字层级之后，建议按下面顺序继续统一。每个模块先出规则，再选一个业务模块试点，最后逐步应用。

| 模块 | 需要统一的内容 | 建议节奏 |
| --- | --- | --- |
| 颜色 / 设计风格 | 品牌色、背景色、正文色、弱文字、危险色、成功色、警告色、暗色页面规则。 | 文字层级后第一批整理，避免页面越做越花。 |
| 间距 | 页面安全边距、区块间距、卡片内边距、列表项间距、按钮组间距。 | 和卡片一起整理，优先规范消息、组局列表、详情页。 |
| 卡片 | 圆角、阴影、边框、背景、内容密度、卡片内标题 / 正文 / 操作区布局。 | 适合作为第二个试点模块，消息卡片和组局卡片先统一。 |
| 图标 | 图标尺寸、描边 / 面性风格、背景底形、红点位置、状态图标颜色。 | 在图标素材确认后统一，不直接混用不同风格图标。 |
| 按钮 | 主次按钮、危险按钮、文字按钮、卡片小按钮、禁用态、加载态。 | 已有基础类，后续需要降低过重字重并补状态。 |
| 标签 / 状态 | 审核通过、待处理、未读、成功、失败、警告等标签样式。 | 跟消息和订单状态一起收敛。 |
| 列表 | 单行列表、双行列表、消息列表、操作列表、空状态。 | 卡片规则稳定后再整理。 |
| 表单 | label、输入框、选择器、上传、错误提示、帮助文字。 | 登录链路已有基础，业务表单后续复用。 |
| 反馈状态 | loading、空状态、错误状态、toast 文案、确认弹窗。 | 接口页面增多后统一。 |

## 当前约定

- 页面原有布局类可以与 `enjoy-` 类叠加，例如 `class="field enjoy-field enjoy-field--comfortable"`。
- 页面级 WXSS 只保留定位、宽度、间距等版式规则；颜色、圆角、字号、高度优先使用 `enjoy-` 样式。
- 验证码入口在登录链路统一文案为“获取验证码”；倒计时可通过周边文案表达，例如“59s 后可 获取验证码”。
- 后续统一首页时，应先确认原型当前画布，再为首页业务模块单独定义视觉规则。
