# 样式统计与合并候选盘点

记录日期：2026-06-28

本轮只做统计和归类，不合并、不替换、不调整任何页面样式。

## 统计范围

- 统计文件：项目内全部 `.wxss`
- 文件数量：147 个
- 样式块：6752 个
- 声明数量：30437 条
- 样式行数：51927 行
- 样式体积：约 880 KB

## 现有公共样式

当前已有公共 / shared 样式文件：

- `styles/enjoy-ui.wxss`
- `pages/shared/module.wxss`
- `pages/profile/profile-white-page.wxss`
- `pages/profile/service-center/invite/shared.wxss`
- `pages/profile/system-management/block-settings/shared.wxss`
- `pages/profile/system-management/feedback/shared.wxss`
- `pages/profile/system-management/report-center/shared.wxss`

结论：

- `styles/enjoy-ui.wxss` 已经有输入框、按钮、验证码框、链接、勾选圆等基础样式，但覆盖范围主要集中在登录 / 注册早期页面。
- `profile-white-page.wxss` 已经抽出了一套白色个人中心页面样式，适合继续作为“我的 / 白底列表卡片页”的基础。
- 系统管理里的 `block-settings`、`feedback`、`report-center` 已经各自抽了 shared，但它们之间还存在按钮、卡片、标签、底部操作栏、表单控件的重复。
- 组局、首页、地图等模块目前更偏页面内私有样式，公共沉淀较少。

## 可合并优先级

### P0：先定设计 token，不改页面

建议先沉淀文档或 token 文件：

- 颜色 token：文字、背景、边框、状态、主题色
- 字号 token：辅助、正文、标题、页面标题、数字
- 间距 token：4 到 48 的常用档位
- 圆角 token：小、中、大、胶囊、圆形
- 阴影 token：白底卡片、浮层、深色发光

### P1：优先合并已有共识组件

适合后续优先动：

- 按钮体系
- 状态标签 / chip
- 白底卡片 / 列表行
- 搜索框 / 输入框 / 上传格
- 底部固定操作栏
- 底部 sheet / 遮罩

### P2：按模块合并

建议顺序：

1. `pages/profile/system-management`：已有多个 shared，合并收益高，风险相对可控
2. `pages/profile/asset-center` 与 `pages/profile/service-center`：白底卡片、标签、列表重复明显
3. `pages/game`：样式量最大，但业务状态多，建议分批抽按钮、状态、卡片
5. `pages/home`：视觉差异大，最后处理，避免破坏首页效果

## 不建议现在合并的内容

- 强还原原型的单页私有布局
- 首页 / 元宇宙 / 地图主视觉装饰
- 绝对定位的图形、地图、封面、特殊按钮
- 原型还没有最终确认的页面细节
- 与用户截图像素对齐相关的临时样式

## 后续建议

建议下一阶段只做“规范定稿”，仍不直接批量改页面：

1. 新建或补充 `docs/design-system.md`
2. 定义颜色、字号、间距、圆角、阴影、按钮、卡片、标签、表单规范
3. 明确哪些页面继续保留私有样式
4. 选一个低风险模块试点，比如系统管理的反馈 / 举报 / 屏蔽设置
5. 试点通过后，再逐模块替换公共样式
