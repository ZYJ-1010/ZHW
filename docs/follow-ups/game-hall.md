## 分类口径

- 一级分类回答“这局的主要目的是什么”，例如社交、任务、探索、成长、圈层。
- 二级细分回答“这个目的下具体怎么玩”，例如社交局里的饭局、桌游局、同城散步局。
- `标准局 / AA局 / 众筹局 / 押金局 / 公益局` 属于玩法、收费或结算方式，放在筛选栏的 `类型` 维度，不作为一级分类。
- 同一个局可以同时拥有目的分类和玩法类型，例如 `押金读书打卡局` 可归为 `成长局 > 读书局 / 打卡局`，同时标记为 `押金局`。
