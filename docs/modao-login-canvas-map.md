# 墨刀登录相关画布与代码对应关系

本文只记录工程实现映射，不修改 `00.文档` 下的正式需求文档。

## 规则

1. 墨刀里的“画布”不一定等于小程序路由。
2. 一个小程序路由可以用内部状态承载同一业务里的多个墨刀页面。
3. 后续做页面前，先补充对应画布的尺寸清单，再改 WXML/WXSS/JS。
4. 微信系统授权成功属于小程序动态反馈，不按普通静态墨刀页面逐像素还原。

## 邀请注册 / 已注册用户登录

墨刀位置：

```text
邀请注册 -> 已注册用户登录
```

当前画布内页面与代码对应：

| 墨刀页面 | 小程序实现 | 说明 |
| --- | --- | --- |
| 登录主页 | `pages/login/index`，`loginMode = home` | 只展示手机号登录、账号密码登录、协议勾选 |
| 验证码登录 | `pages/login/index`，`loginMode = codeVerify` | 手机号登录后的 6 位验证码页 |
| 账号密码登录 | `pages/login/index`，`loginMode = account` | 账号、密码、找回密码、验证码登录、微信登录 |
| 微信授权 | `pages/login/index`，`loginMode = wechatAuth` | 展示微信图标、授权说明、允许、拒绝 |
| 进入启动页面 | `pages/entry/index?mode=login` | 微信登录成功后的过场；展示后进入登录后首页 |
| 进入启动页面 | `pages/entry/index` | 小程序首次打开的进入页 |

## 忘记密码找回 / 找回密码

墨刀位置：

```text
邀请注册 -> 忘记密码找回
```

当前画布内页面与代码对应：

| 墨刀页面 | 小程序实现 | 说明 |
| --- | --- | --- |
| 找回密码-验证手机号 | `pages/login/forgot/index`，`step = phone` | 手机号、验证码、下一步、返回登录 |
| 找回密码-设置新密码 | `pages/login/forgot/index`，`step = password` | 新密码、确认密码、确认修改 |
| 重置成功 | `pages/login/forgot/index`，`step = success` | 成功提示、返回登录 |

## 新用户邀请注册登录

墨刀位置：

```text
邀请注册 -> 新用户邀请注册登录
```

当前代码对应：

| 墨刀页面 | 小程序实现 | 说明 |
| --- | --- | --- |
| 邀请码识别 / 邀请注册入口 | `pages/login/invite/index` | 输入或识别邀请码 |
| 继续登录注册 | `pages/login/index` 携带邀请上下文 | 邀请关系随登录提交 |

## 登录前与登录后首页

| 墨刀页面 | 小程序实现 | 说明 |
| --- | --- | --- |
| 登录前首页 | `pages/home/guest/index` | 未登录状态首页，点击注册/登录进入 `pages/login/index` |
| 玩家首页 | `pages/home/index` | 登录成功后的玩家首页 |
