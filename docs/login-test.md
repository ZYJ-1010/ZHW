# 登录测试说明

本文只记录当前工程测试口径，不修改 `00.文档` 下的正式需求文档。

## 当前业务口径

1. 小程序默认先进入 `pages/entry/index`。
2. 进入页自动跳转，或点击 `GO` 进入登录前首页 `pages/home/guest/index`。
3. 登录前首页点击 `注册/登录` 后进入普通登录页 `pages/login/index`。
4. 普通登录页先显示登录主页，只展示 `手机号登录`、`账号密码登录` 和协议勾选。
5. 点击 `手机号登录` 后进入接收验证码登录页，展示已发送的脱敏手机号。
6. 点击 `账号密码登录` 后进入账号密码登录表单。
7. 微信授权登录是 `pages/login/index` 的内部状态，不单独作为顶层路由。
8. 找回密码是独立页面：`pages/login/forgot/index`。
9. 邀请码注册是独立页面：`pages/login/invite/index`，不放在普通登录页里。

## 启动入口流程

1. 打开微信开发者工具。
2. 导入项目目录：`E:\项目\03周总\01enjoy`。
3. 不单独指定启动页面，直接点击编译。

预期：

- 先看到黑底的 `真好玩 / ZHEN HAO WAN / GO` 进入页。
- 约 1 秒后自动进入登录前首页；也可以点击 `GO` 立即进入。
- 登录前首页显示 `HELLO, 玩家!`、启动旅程卡片、`注册/登录`、发起组局、局前大厅、附近正在发生。
- 点击 `注册/登录` 后进入 `pages/login/index`。

## 测试模式

当前项目默认使用 mock 模式，不需要真实服务器也能测试登录流程。

```js
// config/env.js
const currentEnv = ENV.MOCK
```

登录成功后会写入本地缓存：

```text
enjoy_token
enjoy_user
```

## 手机号登录流程

1. 打开微信开发者工具。
2. 导入项目目录：`E:\项目\03周总\01enjoy`。
3. 启动页面设为 `pages/login/index`。
4. 点击编译。
5. 确认先看到登录主页。
6. 勾选用户协议和隐私协议。
7. 点击 `手机号登录`。
8. 预期进入验证码登录页，显示手机号 `138****8888`，并提示验证码已发送。
9. 点击验证码输入框，输入验证码 `123456`。
10. 点击 `登录`。

预期：提示 `登录成功`，随后进入 `pages/home/index`。

## 账号密码登录流程

1. 打开 `pages/login/index`。
2. 确认先看到登录主页。
3. 勾选用户协议和隐私协议。
4. 点击 `账号密码登录`。
5. 输入账号 `13888888888`。
6. 输入密码 `Test123456`。
7. 点击 `登录/注册`。

预期：提示 `登录成功`，随后进入 `pages/home/index`。

## 微信授权登录流程

1. 打开 `pages/login/index`。
2. 点击 `微信登录`。
3. 进入微信授权界面，确认能看到微信图标、授权说明、`允许` 和 `拒绝`，页面无需拖动。
4. 点击 `允许`。

预期：接口成功后进入墨刀的 `进入启动页面` 过场，再进入 `pages/home/index`；接口失败则停留在微信授权页并提示错误。

点击 `拒绝` 的预期：返回普通登录页，提示已拒绝授权。

## 找回密码流程

1. 打开 `pages/login/index`。
2. 点击 `找回密码`。
3. 输入手机号 `13888888888`。
4. 点击 `获取验证码`。
5. 输入验证码 `123456`。
6. 点击 `下一步`。
7. 输入新密码 `Test123456`。
8. 再次输入新密码 `Test123456`。
9. 点击 `确认修改`。

预期：进入 `密码重置成功` 页面；点击 `去登录` 后返回 `pages/login/index`。

如果把启动页面直接设为 `pages/login/forgot/index`，点击 `返回登录` 也应回到 `pages/login/index`。

## 邀请注册流程

1. 启动页面设为 `pages/login/invite/index`。
2. 输入邀请码 `ENJOY2026`。
3. 点击 `确认邀请码`。
4. 点击 `继续登录注册`。
5. 进入 `pages/login/index` 后，页面应显示 `已识别邀请`。
6. 勾选用户协议和隐私协议。
7. 点击 `手机号登录`。
8. 预期进入验证码登录页，显示手机号 `138****8888`，并提示验证码已发送。
9. 输入验证码 `123456`。
10. 点击 `登录`。

预期：提示 `登录成功`，随后进入 `pages/home/index`；mock 返回中包含 `inviteRelation`。

邀请页点击 `普通登录` 的预期：清空邀请上下文，回到 `pages/login/index`，登录页不显示邀请提示。

## 异常测试

| 操作 | 预期 |
| --- | --- |
| 不勾选协议点击 `登录/注册` | 提示先同意用户协议和隐私协议，不跳首页 |
| 不勾选协议点击 `账号密码登录` | 提示先同意用户协议和隐私协议，不跳首页 |
| 验证码页未输入满 6 位点击 `登录` | 提示请输入 6 位验证码，不进入首页 |
| 空手机号点击 `获取验证码` | 提示先输入手机号 |
| 手机号或验证码错误后登录 | 提示手机号或验证码错误 |
| 找回密码页验证码输入 `123457` 后点下一步 | 提示手机号或验证码错误，不进入设置新密码页 |
| 找回密码页密码包含符号或不含字母/数字 | 提示仅支持字母和数字，长度8-20位 |
| 找回密码页两次新密码不一致 | 提示两次输入的新密码不一致 |
| 邀请页输入错误邀请码 | 提示邀请码无效，不能继续登录注册 |

## 切换真实服务器

修改：

```js
// config/env.js
const currentEnv = ENV.PROD
```

同时把真实接口域名改成服务器地址：

```js
const serverMap = {
  [ENV.MOCK]: '',
  [ENV.PROD]: 'https://你的真实接口域名'
}
```

当前普通登录闭环预留的接口：

```text
POST /api/app/invites/verify
POST /api/app/auth/phone-code
POST /api/app/auth/phone-login
POST /api/app/auth/password-login
POST /api/app/auth/wechat-login
POST /api/app/auth/password/reset
```
