# 墨刀尺寸到小程序 rpx 换算说明

本文只记录工程实现规则，不修改 `00.文档` 下的正式需求。

## 当前规则

- 墨刀原型画布按 iPhone 规格设计，当前登录流程画布宽度为 `375`。
- 微信小程序 `rpx` 以 `750rpx` 作为屏幕宽度基准。
- 因此当前换算关系固定为：

```text
小程序 rpx = 墨刀标注数值 * 2
```

## 应用范围

以下尺寸都按同一规则换算：

- `left`
- `top`
- `width`
- `height`
- `font-size`
- `line-height`
- `border-radius`
- `margin`
- `padding`
- 元素之间的横向、纵向间距

颜色、透明度、文案内容不做数值换算，按墨刀标注直接使用。

## 注意事项

- 墨刀右侧标注面板切换 `pt`、`rpx` 时，如果数字没有变化，就仍按 375 画布数值理解，进入小程序代码时继续乘以 2。
- 不按浏览器截图的显示大小估算尺寸，因为浏览器缩放、墨刀缩放和截图缩放都会影响视觉判断。
- 页面开发时优先使用墨刀右侧标注的 `CSS` 数值，再按本规则换算到 WXSS。
- 如果后续墨刀画布不是 `375` 宽，需要先重新确认画布宽度，再调整换算规则。

## 示例

```text
墨刀：width: 313
小程序：width: 626rpx

墨刀：font-size: 17
小程序：font-size: 34rpx

墨刀：left: 31
小程序：left: 62rpx
```
