# 原型 PT 与小程序前端视觉差距审查（2026-07-19）

## 范围与结论

- 对照来源：`docs/prototype-pt-20260719/all-screens-pt.json`（105 个带页面标识画布、23,418 个元素）以及小程序 `app.json` 的 110 条路由、148 个 WXML 和 151 个 WXSS。
- 本次是静态代码与原型标注审查；未把演示用户、头像、金额、榜单数据作为实现要求。
- 结论：前端路由覆盖度较高，但核心界面的视觉语言尚未统一。首页、角色申请、地图/关系网、再玩一局为高优先级差距；大量功能页仍使用通用灰蓝色卡片和 CSS 自绘图标，未按对应原型的 PT、色彩和组件落地。

## 原型基准

- 原型基准画布：`375 × 812pt`，小程序应按 `1pt = 2rpx` 换算。
- 首页深色视觉主色：`#000000`、`#00F2FF`、`#ADFF2F`、`#FF006E`、`#F0D291`。
- 功能页浅色视觉主色：`#F6F7FB`、`#1F2937`、`#4B5563`、`#2563EB`、`#16A34A`。
- 现有前端高频使用 `#111827`、`#6B7280`、`#3B82F6`、`#22C55E`、`#F3F4F6`；它们与原型接近但并非同一组色值，不能再以通用 Tailwind 色替代原型色。

## 全局组件差距

1. 图标来源不统一：当前仍有 CSS 自绘放大镜、箭头、游戏机和文字图标；应优先使用已归档的 94 个 SVG，再按页面映射引入项目内 assets。
2. 颜色未收敛：首页应固定使用原型深色令牌，功能页应固定使用原型浅色令牌；不能继续混用 `#007BD3` 页面底、Tailwind 灰蓝与原型青色。
3. PT 换算未系统执行：部分页面用 `width: 638rpx`、`704rpx` 等手工尺寸，但没有页面级标注映射；应按“原型元素 pt × 2”逐页落位。
4. 页面壳不一致：原型设备状态栏不应实现；当前部分 `home-master` 页面使用 750rpx 手机框/占位壳，实际小程序页面不需要该层。
5. 远程资源风险：关系网使用远程 PNG；按项目规则应先将确定使用的素材放入项目内 assets，避免视觉与发布环境不一致。

## 建议实施顺序

1. 首页三角色 + 本周玩霸榜。
2. 角色申请条件页、资料填写页、审核状态页。
3. 局前大厅、发起组局、再玩一局三页。
4. 地图与关系网。
5. 我的、消息、登录邀请、系统管理功能页。

- 未修改小程序、后端或后台代码。
- 未复制原型中的用户头像、局封面、金额、排名和其他演示数据。
- 未做真机截图叠加；页面实施后需使用同尺寸截图按 PT 再次验收。
