# 开发依据冻结记录

本项目按以下文档作为一期后端与后台工程实施依据：

1. `文档/PRD.md`
2. `文档/功能清单.md`
3. `文档/接口、数据库初稿.md`，其中第 20 章作为接口、字段、枚举、数据库最终对接口径。
4. `文档/需求细节、验收标准.md`
5. `文档/项目节点.md`
6. `plan.md`

## 冲突处理规则

- 一期范围和验收以 `PRD.md`、`功能清单.md` 为准。
- 接口路径、字段、枚举、数据库字段以 `接口、数据库初稿.md` 第 20 章为准。
- 需求细节以 `需求细节、验收标准.md` 为准。
- 排期节点以 `项目节点.md` 为准。
- `plan.md` 负责把以上内容拆成工程实施步骤。
