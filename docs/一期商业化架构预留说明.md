# 一期商业化架构预留说明

状态：仅架构预留；一期前端不展示、接口不开放、不会创建有偿订单或发起真实支付。

## 已预留的数据边界

- 局：沿用 `gameType`、`price`、`profitTemplate`，新增 `distributionMethod`、`paymentStatus`；一期免费局固定为 `none`／`not_required`。
- 支付订单：`payment_orders` 预留订单类型、业务类型、服务提供者、分配方式、履约状态和扩展元数据。
- 一对一与定制服务：`commercial_service_orders`，支持 `one_to_one`、`custom_service` 两种订单类型。
- 分配明细：`commercial_order_allocations`，支持多人协作行家的逐笔分配记录。

## 二期状态机

`created → pending_payment → escrowed → settlement_pending → settled`

退款支路：`escrowed／settlement_pending → refund_pending → refunded`；支付前可关闭为 `closed`。

## 分配方式

- `equal_split`：平均分配
- `voluntary`：随喜分配
- `contribution_based`：按贡献分配

## 一期约束

- 小程序仅可创建免费局，前端不得展示上述字段。
- 有偿局、资金托管、退款、赔付、分账回调均未开放。
- `AllowGuideEscortForPaid` 作为后台运营规则字段预留，默认关闭；二期须在支付合规、商户主体及消费者权益方案确认后方可开启。
