# 一期最终业务口径与差异清单

确认日期：2026-08-02
适用范围：小程序、后台、Go API、数据库迁移和后续验收。
本文件以本次确认的业务决定为准，覆盖历史 PRD、验收文档和过程文档中的不同写法。

## 一、已确认的最终业务口径

| 事项 | 最终口径 |
| --- | --- |
| 地图与元宇宙 | 一期点击提示“暂未开放”即可，无需删除页面或接口。 |
| 注册邀请码 | **仅领路人**可生成注册链接、二维码和海报；普通玩家、仅行家身份均不可生成或查看该入口。平台官方仅能在后台生成和分配邀请码。 |
| 新用户注册 | 首次注册必须通过手机号和短信验证码，并填写有效邀请码。 |
| 加载页微信识别 | 加载页调用微信登录凭证检测微信是否已绑定。已绑定且账号存在时自动登录，不再重复进入登录/注册页。 |
| 未绑定微信用户 | 未识别到已绑定微信账号时，进入登录/注册页。首次注册需手机号、短信验证码和邀请码；已注册用户通过手机号验证码或密码登录时无需再次填写邀请码。 |
| 微信绑定 | 注册或登录后提示用户绑定微信；用户可暂不绑定。绑定后，下次在加载页可自动登录。 |
| 密码绑定 | 用户在个人资料/系统设置中设置密码；未设置密码时不得使用密码登录。 |
| 行家、领路人申请 | 一期取消会员等级和付费门槛；保留实名认证、申请资料、资格条件、后台审核和白名单开通。 |
| 直属领路人护航 | 已从一期范围移除，不开放护航入局。 |
| 有偿局、一对一、定制服务 | 已从一期范围移除；不作为一期架构预留验收项。 |
| 入局后退出 | 必须扣信用分；扣分数值和启用状态由后台“信用扣分规则”设置。 |

## 四、已核查一致的主流程

- 创建局后先进入后台审核，审核通过后才公开招募；
- 报名时间、满员、重复申请和角色权限均由后端校验；
- 拒绝申请必须填写理由，并通知申请人；
- 申请中用户可以撤回；已入局、未开局成员可以退出；
- 满员建群，开局后锁定后续报名；非成员不能进入局内 IM；
- 服务确认后进入评价，全部必评完成后局进入已完成；
- 行家和领路人需要实名认证及审核/白名单后才获得对应能力；
- 后台具备邀请码、局模板、等级、经验、信用、成就、技能上限和审核待办等管理入口或接口。

## 五、最终结论

当前业务口径已明确。代码层面唯一需要继续完成并上线验证的事项是：**入局后、开局前退出必须按后台配置扣除信用分**。
地图、元宇宙、二期演示数据、收费局、会员门槛、护航、有偿局、一对一和定制服务均按本文件第一部分执行，不再作为一期整改问题。
