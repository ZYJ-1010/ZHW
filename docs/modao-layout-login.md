# 墨刀登录相关尺寸清单

本文只记录工程实现尺寸，不修改 `00.文档` 下的正式需求文档。

## 通用换算

- 墨刀画布：375px / rpx 标注宽。
- 小程序设计稿：750rpx。
- 采用规则：墨刀标注在 `rpx` 模式下直接按小程序 rpx 使用；截图只能确认比例时，用 `375 -> 750rpx` 的页面比例辅助。

## 已注册用户登录 - 账号密码登录

来源：墨刀标注模式 + 用户截图标注。

| 元素 | 当前采用尺寸 / 位置 | 说明 |
| --- | --- | --- |
| 页面宽 | `750rpx` | 375 画布对应 750rpx |
| 主内容左右边距 | `62rpx` 左右 | 与登录主页主按钮边距一致 |
| 输入框宽 | `626rpx` | `750 - 62 * 2` |
| 输入框高 | `88rpx` | 延续墨刀登录输入框比例 |
| 输入框圆角 | `20rpx` | 浅灰背景 |
| 登录/注册按钮宽 | `410rpx` | 截图显示比底部双按钮窄，居中 |
| 登录/注册按钮高 | `88rpx` | 与当前输入框接近 |
| 验证码登录/微信登录按钮组总宽 | `626rpx` | 与输入框同宽 |
| 验证码登录/微信登录单按钮 | `(626 - 14) / 2 = 306rpx` | 两按钮等宽 |
| 找回密码 | 右侧弱入口 | 不做主按钮 |

## 忘记密码找回

来源：用户截图 + 墨刀左侧页面树。

墨刀包含 3 个页面：

1. 找回密码-验证手机号
2. 找回密码-设置新密码
3. 重置成功

### 验证手机号页

| 元素 | 当前采用尺寸 / 位置 | 说明 |
| --- | --- | --- |
| 页面宽 | `750rpx` | 375 画布对应 750rpx |
| 内容左右边距 | `62rpx` | 与账号密码页一致 |
| 页面标题 | 居中，`找回密码` | 字号暂用 `42rpx` |
| 进度条 | 3 段，第一段高亮 | 紫粉渐变 + 灰色 |
| 步骤标题 | `验证手机号` | 居中 |
| 输入框 | `626rpx * 104rpx` | 浅灰背景，大圆角 |
| 下一步按钮 | `626rpx * 104rpx` | 紫粉渐变 |
| 返回登录 | 居中弱文字 | `← 返回登录` |
